## Prioritization rationale

G01/G02 are shared roots across every feature. G03 is the highest-impact safe
unowned code slice established in this recovery: it connects two existing
components, adds no authority and can be tested without secrets or deployments.
G04 is more immediately red but already has a writer. G05/G07/G08/G23 require
broader integration proof and must not be rushed by adding frameworks. This
increment resolves the G03 **source producer** gap only; it does not close the
whole offline issue, authorize live media publication or claim distribution readiness.
